# PC-doctor
PC Doctor Pro is a free, open-source Windows utility that puts every tool you need in one dark dashboard. It scans CPU, RAM, GPU, disks, motherboard, BIOS, network and battery; safely installs and updates drivers through Windows Update (with automatic System Restore points); deep-cleans your system; runs CPU/RAM/disk benchmarks; exports HTML reports; and includes a full Overclock & Undervolt center with one-click ECO/Balanced/Performance profiles, manual power-limit tuning and a live stability monitor. A built-in one-click Repair tool fixes broken installs on its own. 100% local — no accounts, no cloud, no telemetry.
